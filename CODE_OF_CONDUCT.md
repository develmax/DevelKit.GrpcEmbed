# Code of Conduct

## Our commitment

GrpcEmbed welcomes contributors of every background and experience level. Help
make participation respectful, inclusive, and safe, regardless of age, disability,
ethnicity, gender identity, nationality, religion, or sexual orientation.

## Expected behavior

- Be considerate, use welcoming language, and respect differing viewpoints.
- Give constructive feedback about code and ideas rather than personal traits.
- Accept responsibility for mistakes and help resolve disagreements respectfully.
- Respect privacy and never publish another person's private information.

Harassment, discriminatory language, sexualized content, threats, personal attacks,
and sustained disruption are unacceptable.

## Scope and enforcement

This policy applies to repository issues, pull requests, discussions, and other
project spaces, including representing the project publicly. Maintainers may edit
or remove inappropriate contributions and warn, restrict, or ban participants.
Responses should be proportionate to the behavior, its impact, and repetition.

## Reporting

For non-sensitive concerns, contact the [maintainer](https://github.com/develmax)
in a repository issue without publishing personal details. For sensitive concerns,
use a private contact channel listed on the maintainer's profile; if none is
available, request a confidential contact channel without describing the incident
publicly. Maintainers should handle reports confidentially where possible, disclose
information only as needed to resolve a report, and avoid retaliation.

Abusive content on GitHub can also be reported privately to GitHub using the
platform's **Report content** feature. That report goes to GitHub, not the project
maintainer. For software vulnerabilities, follow [SECURITY.md](SECURITY.md) instead.
