# Changelog

Все заметные изменения проекта документируются в этом файле.

## 1.0.0 — 2026-09-15

Первый стабильный выпуск.

### Добавлено

- Runtime discovery существующих ASP.NET Core MVC-контроллеров.
- Стандартные native unary gRPC endpoints и Protocol Buffers без JSON.
- Контрактные .NET-клиенты на обычных C#-интерфейсах.
- Экспорт `.proto`, descriptor set, schema manifest и SHA-256 schema hash.
- gRPC Server Reflection, authorization, MVC filters, DI, validation и cancellation.
- Стабильные номера полей, reserved fields и диагностика несовместимых изменений.
- Поддержка .NET 6, 7, 8, 9 и 10.
- Sample-приложения, integration tests и BenchmarkDotNet-проект.
